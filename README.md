# Website Kynovia

Site estatico da Kynovia organizado para deploy na Vercel.

## Estrutura

- `index.html`: site institucional.
- `modelos/index.html`: catalogo dos modelos.
- `modelos/*/index.html`: paginas demonstrativas navegaveis.
- `produtos/index.html`: area de produtos.
- `privacidade/index.html` e `termos/index.html`: paginas reservadas para conteudo juridico.

## Deploy na Vercel

Importe este diretorio como um projeto estatico. Nao ha etapa de build obrigatoria.
